# HelpNest

HelpNest is a browser-based technology-help interface prototype.

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. No API key or package installation is needed for the current frontend prototype.

## Project layout
- `index.html` — page structure
- `css/styles.css` — styles
- `js/app.js` — current application logic
- `assets/` — images and other static files

## Prototype limitations
Ticket updates, technician chat replies, and technician availability are currently simulated in browser JavaScript. The Zoom URL is a placeholder. Real technician support, persistent tickets, and real video calls require backend/service integration.
\n## JavaScript files\n- `js/fixes.js`: quick-fix instructions and problem-category detection.\n- `js/support.js`: ticket view and simulated technician-support interactions.\n- `js/app.js`: main interface and navigation.\n\nNote: technician availability, chat replies, waiting times, and video-call readiness are still demo/simulated. The Zoom URL is a placeholder and must not be treated as a real support link.\n
